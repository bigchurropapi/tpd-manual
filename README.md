# TPD Manual — mobile reference

Scrollable, searchable reference for the Toledo Police Department Manual (October 2026 edition, public record) plus a plain-language case-law section for patrol.

Static site: no build step, no backend. `index.html`, `app.js`, `styles.css`, `data.json` (manual), `cases.json` (case law).

Case summaries are editorial training aids, not legal advice and not department policy.
